# Erwang Blog 阿里云 + 宝塔部署说明

## 1. 你需要在哪些地方配置

### 阿里云控制台
1. **域名解析**
   - 给 `erwang.me` 和 `www.erwang.me` 添加 A 记录，指向你的 ECS 公网 IP。
2. **安全组**
   - 放行：`22`（建议只允许你的 IP）、`80`、`443`
   - 不要对公网开放：`3306`、`9090`、`8888`

### 宝塔面板
1. **网站**
   - 新建站点：域名填 `erwang.me,www.erwang.me`
   - 网站根目录：`/www/wwwroot/erwang/frontend/dist`
2. **Nginx 配置**
   - 把 `deploy/bt-nginx-site.conf.example` 内容合并到站点配置
3. **SSL**
   - 申请 Let's Encrypt 或导入阿里云证书
   - 开启强制 HTTPS
4. **数据库**
   - 创建数据库：`blog`
   - 创建账号：`bloguser`
   - 给 `bloguser@127.0.0.1` 授权

## 2. 仓库里已经准备好的文件

- `backend/sql/init.sql`：完整建表 SQL（已补全缺失表）
- `deploy/erwang.service`：systemd 服务文件
- `deploy/erwang-backend.env.example`：后端环境变量模板
- `deploy/bt-nginx-site.conf.example`：宝塔 Nginx 配置模板

## 3. 服务器目录约定

```bash
/www/wwwroot/erwang/
  ├── frontend/dist
  ├── backend/app.jar
  ├── backend/sql/init.sql
  ├── uploads
  └── deploy
```

## 4. 服务器上执行的命令

### 4.1 创建目录
```bash
mkdir -p /www/wwwroot/erwang/{frontend/dist,backend,uploads,deploy}
mkdir -p /www/wwwroot/erwang/backend/sql
```

### 4.2 上传代码产物
把以下内容上传到服务器：
- `frontend/dist/*` → `/www/wwwroot/erwang/frontend/dist/`
- `backend/target/*.jar` → `/www/wwwroot/erwang/backend/app.jar`
- `backend/sql/init.sql` → `/www/wwwroot/erwang/backend/sql/init.sql`
- `deploy/*` → `/www/wwwroot/erwang/deploy/`

### 4.3 配置后端环境变量
```bash
cp /www/wwwroot/erwang/deploy/erwang-backend.env.example /www/wwwroot/erwang/deploy/erwang-backend.env
vi /www/wwwroot/erwang/deploy/erwang-backend.env
```

必改项：
- `DB_PASSWORD`
- `JWT_SECRET`
- `CORS_ORIGINS`（默认已写成 `https://erwang.me,https://www.erwang.me`）

### 4.4 初始化数据库
```bash
mysql -uroot -p
```

然后执行：
```sql
CREATE DATABASE IF NOT EXISTS blog DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER IF NOT EXISTS 'bloguser'@'127.0.0.1' IDENTIFIED BY '你的数据库密码';
GRANT ALL PRIVILEGES ON blog.* TO 'bloguser'@'127.0.0.1';
FLUSH PRIVILEGES;
```

导入表结构：
```bash
mysql -uroot -p blog < /www/wwwroot/erwang/backend/sql/init.sql
```

### 4.5 安装 systemd 服务
```bash
cp /www/wwwroot/erwang/deploy/erwang.service /etc/systemd/system/erwang.service
systemctl daemon-reload
systemctl enable erwang
systemctl start erwang
systemctl status erwang
```

查看日志：
```bash
journalctl -u erwang -f
```

## 5. 本地打包命令

### 前端
```bash
cd frontend
npm install
npm run build
```

### 后端
```bash
cd backend
mvn clean package -DskipTests
```

### 检查站点
- `https://erwang.me`
- 登录/注册
- 图片上传
- 文章详情

## 7. 关键说明

1. 前端生产环境已经使用 `VITE_API_BASE=/api`，适合宝塔 Nginx 反代。
2. 后端上传目录已改为可配置，生产默认：`/www/wwwroot/erwang/uploads`
3. 不要开放 MySQL 到公网。
4. 建议用 `systemd` 托管后端，不用宝塔 Java 项目管理器来做长期生产运行。
